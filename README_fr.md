# Slovingo-de-fr 🇩🇪 🇫🇷

**Apprendre l'allemand de manière ludique — pour les enfants à partir de 8 ans**

Un cours d'allemand construit sur le framework [Slovingo](https://github.com/lstux/Slovingo), conçu spécialement pour les enfants francophones.

## 📚 Qu'est-ce qu'il y a dedans ?

- **Fiches** : Cartes interactives avec prononciation et audio
- **Séries** : Progressions thématiques avec difficulté croissante
- **Dialogues** : Conversations amusantes avec des personnages récurrents
- **Exercices** : Activités variées pour pratiquer et consolider
- **Vocabulaire** : Listes de mots organisées par thème

## ✨ Qu'est-ce qui rend ça spécial ?

Ce cours est conçu **pour les enfants, par l'expérimentation**. Nous adaptons le format d'apprentissage éprouvé de Slovingo pour :
- **Moins formel** : Les introductions sont légères et ludiques
- **Plus interactif** : Éléments gamifiés, récompenses visuelles
- **Visuellement engageant** : Illustrations, emojis et personnalité
- **Flexible** : Ouvert à l'évolution du contenu et du code au fur et à mesure

## 📝 Format

Nous utilisons le **SMD (Slovingo Markdown)**, un format simple et lisible :

- **Cartes audio** avec traductions et explications
- **Tableaux de traduction** pour le vocabulaire
- **Éléments prononçables** {{mot}} pour la prononciation
- **Illustrations** avec légendes
- **Dialogues** avec marqueurs de locuteur

Voir [Format-de-fr.md](./docs/Format-de-fr.md) et la [documentation Slovingo](https://github.com/lstux/Slovingo/tree/main/docs) pour les détails.

## 👨‍👩‍👧 Qui est impliqué ?

C'est un projet d'apprentissage collaboratif. Les tests se font en conditions réelles avec de vrais enfants (en commençant par mon fils 😄), donc le format et le contenu évoluent en fonction de ce qui fonctionne vraiment.

# Prompts pour bannières de thème Slovingo-de-fr-kids

**Format** : 1200×280px (bannière panoramique)  
**Style** : illustration jeunesse, style animation numérique  
**Univers** : Forêt-Noire (Schwarzwald) allemande, animaux sauvages du lieu  
**Licence** : ChatGPT — généré pour ce projet, libre d'usage

**Règles pour ces prompts** (retenues après les rejets ChatGPT) :
- Pas de « style Zootopia » ni de référence à un film existant
- Pas de noms de personnages (ni Lea, Toi, Tom, Oma Hilde, Frau Stachel, Herr Falke…)
- Décrire les animaux par leur espèce, le lieu, la lumière et l'ambiance
- Les animaux représentés sont ceux qu'on trouve réellement dans la Forêt-Noire, pas les personnages de l'histoire

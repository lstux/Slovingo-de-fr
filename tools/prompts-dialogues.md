# Prompts pour illustrations de dialogues — Slovingo de-fr enfants

**Format fiches** : 16/9 paysage (horizontal) — 1920×1080px  
**Format carte accueil** : Portrait mobile optimisé — ~1080×1920px ou 1200×2000px  
**Style** : illustration jeunesse, style animation numérique, couleurs chaudes et lumineuses  
**Univers** : Forêt-Noire allemande, animaux sauvages du lieu  
**Licence** : ChatGPT ou Google Gemini — généré pour ce projet, libre d'usage

**Règles pour ces prompts** (retenues après les rejets) :
- Aucun nom de personnage dans le prompt (les noms ci-dessous sont internes, pour le texte du cours)
- Aucun geste de salutation, de main tendue ou d'échange : chaque animal est dans son activité, la rencontre se fait dans le regard ou la position
- Animaux décrits par espèce, lieu, lumière et ambiance
